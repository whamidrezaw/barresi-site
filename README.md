# سامانهٔ مانیتورینگ لحظه‌ای تغییرات وب‌سایت (نسخهٔ ۲)

این برنامه سایت‌های موردنظر شما (سفارت‌خانه‌ها، صفحات ویزا و نوبت‌دهی، سایت‌های خبری، RSS و کانال‌های عمومی تلگرام) را مداوم بررسی می‌کند و **هر تغییری** را با جزئیات کامل در تلگرام گزارش می‌دهد: چه متنی اضافه شد، چه متنی حذف شد، و در خطوط ویرایش‌شده دقیقاً کدام کلمه با کدام کلمه جایگزین شد.

```
🚨 تغییر در «سفارت آلمان — وضعیت بخش ویزا»
🔗 teheran.diplo.de/ir-de/2752046-2752046
🕒 1405/07/12 – 21:14:42 (2026-10-04)
🟢 1 اضافه · 🟡 1 ویرایش
🔑 کلمات کلیدی: Termin

📍 Die Visastelle und das Rechts- und Konsularreferat …
🟡 Vorsprachetermine … werden ~~derzeit nicht~~ **in eingeschränktem Umfang** vergeben.
```

## ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| **سرعت** | موتور HTTP هر صفحه را در ۰٫۱ تا ۱ ثانیه بررسی می‌کند (حدود ۳۰ برابر سریع‌تر از مرورگر)، پس می‌توان هر ۳۰ تا ۶۰ ثانیه بررسی کرد. با «GET شرطی» (ETag) اگر صفحه عوض نشده باشد، تقریباً هیچ داده‌ای دانلود نمی‌شود. |
| **مرورگر ضدشناسایی** | برای سایت‌های جاوااسکریپتی یا محافظت‌شده (Cloudflare و…) از Patchright با Chrome واقعی استفاده می‌شود. حالت `auto` خودش تشخیص می‌دهد کی مرورگر لازم است. |
| **پوشش کل سایت** | با `crawl` همهٔ صفحات یک بخش (مثلاً همهٔ صفحات فارسی سفارت) زیر نظر گرفته می‌شود: صفحهٔ جدید، صفحهٔ تغییرکرده، صفحهٔ حذف‌شده و فایل‌های PDF جدید یا تغییرکرده. لینک جدید در صفحهٔ اصلی چند ثانیه بعد بررسی و گزارش می‌شود. |
| **اخبار** | نوع `feed` برای RSS/Atom و نوع `items` برای فهرست خبرها، اطلاعیه‌ها یا پست‌های کانال عمومی تلگرام. فقط موارد **جدید** گزارش می‌شوند. |
| **هیچ تغییری گم نمی‌شود** | هر تغییر اول در دیتابیس ذخیره و بعد ارسال می‌شود. اگر تلگرام یا اینترنت قطع باشد یا برنامه ری‌استارت شود، پیام بعداً ارسال می‌شود. حالت cooldown پیام‌ها را تجمیع می‌کند ولی چیزی را حذف نمی‌کند. |
| **گزارش دقیق** | تفاوت کلمه‌به‌کلمه، خط قبل از تغییر برای مشخص شدن محل آن، لینک‌های جدید و حذف‌شده، و فایل HTML گزارش کامل وقتی متن طولانی است. |
| **کلمات کلیدی** | مثلاً «نوبت»، «visa» یا «Termin». تغییرات حاوی آن‌ها با 🚨 مشخص می‌شوند. با `only_keywords` فقط همین تغییرات ارسال می‌شوند. |
| **ضد هشدار کاذب** | صفحهٔ خطا، صفحهٔ چالش ضدربات یا selector شکسته **هرگز** «تغییر» حساب نمی‌شوند؛ پس از چند خطای پیاپی یک هشدار و پس از رفع مشکل یک پیام «برگشت» می‌آید. جابه‌جایی خطوط و فاصله‌های اضافه نادیده گرفته می‌شوند. |
| **ربات تعاملی** | دستورات `/status`، `/check` و `/list` در تلگرام، به‌علاوهٔ گزارش روزانه که نشان می‌دهد سیستم زنده است. |
| **تاریخ شمسی** | زمان‌ها به وقت تهران و با تاریخ شمسی و میلادی نمایش داده می‌شوند. |

```bat
cd "C:\Users\HAMIDREZA\Downloads\prozhe baressi site ha"
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

یا فقط روی `run_windows.bat` دوبار کلیک کنید؛ بار اول همه‌چیز را خودش نصب می‌کند. همهٔ دستورات این راهنما را می‌توانید به شکل `run_windows.bat <دستور>` هم اجرا کنید.

> اگر Chrome نصب نیست: `.venv\Scripts\patchright install chromium`

## ۲) ساخت ربات تلگرام

1. در تلگرام به **@BotFather** پیام دهید، دستور `/newbot` را بفرستید و توکن را کپی کنید (چیزی شبیه `123456789:AAH...`).
2. توکن را در `monitor-config.json` جای `YOUR_TELEGRAM_BOT_TOKEN` بگذارید.
3. ربات خودتان را در تلگرام باز کنید و **Start** را بزنید. برای گروه یا کانال: ربات را عضو کنید (در کانال به‌عنوان ادمین) و یک پیام بفرستید.
4. شناسهٔ چت را بگیرید و در `chat_ids` بگذارید:
   ```bat
   .venv\Scripts\python monitor_system.py chat-id
   ```
5. تست ارسال:
   ```bat
   .venv\Scripts\python monitor_system.py test-telegram
   ```

می‌توانید چند گیرنده داشته باشید: `"chat_ids": ["123456789", "-1001234567890"]`.
اگر نمی‌خواهید توکن داخل فایل باشد، متغیر محیطی `TELEGRAM_BOT_TOKEN` را تنظیم کنید.

## ۳) افزودن سایت‌ها

**گام ۱ — تحلیل صفحه:**
```bat
.venv\Scripts\python monitor_system.py inspect "https://teheran.diplo.de/ir-fa"
```
خروجی نشان می‌دهد آیا HTTP ساده کافی است یا مرورگر لازم است. همچنین بهترین بخش‌های محتوایی (selector)، فهرست‌های تکراری (برای خبرها) و فیدهای RSS سایت را پیشنهاد می‌دهد، همراه با یک نمونه تنظیم آماده.

**گام ۲ — دیدن دقیق متنی که زیر نظر گرفته می‌شود:**
```bat
.venv\Scripts\python monitor_system.py inspect "https://teheran.diplo.de/ir-fa" --selector "#main"
```

**گام ۳ — افزودن به `watches` در `monitor-config.json` و آزمایش:**
```bat
.venv\Scripts\python monitor_system.py validate
.venv\Scripts\python monitor_system.py preview de_embassy_home
.venv\Scripts\python monitor_system.py once --dry-run
```
`once --dry-run` همه را یک بار بررسی می‌کند و پیام‌ها را به‌جای تلگرام در صفحه چاپ می‌کند. بار اول فقط «baseline» (نسخهٔ مرجع) ذخیره می‌شود؛ از بار دوم تغییرات گزارش می‌شوند.

**گام ۴ — اجرای دائمی:**
```bat
.venv\Scripts\python monitor_system.py run
```
(برای توقف: Ctrl+C. برای کار ۲۴ ساعته، بخش «استقرار روی سرور» را ببینید.)

## انواع مانیتور

### `page` — یک صفحه (پیش‌فرض)، با امکان خزش کل بخش
```json
{
  "id": "de_embassy_home",
  "name": "سفارت آلمان",
  "url": "https://teheran.diplo.de/ir-fa",
  "selector": "#main",
  "track_links": true,
  "interval_seconds": 90,
  "keywords": ["ویزا", "نوبت", "visa", "termin"],
  "crawl": { "include": ["teheran\\.diplo\\.de/ir-fa/"], "max_pages": 150, "max_depth": 3, "interval_seconds": 900 }
}
```
- `selector`: فقط همین بخش صفحه مقایسه می‌شود، نه منو و تبلیغ. اگر چند عنصر را بگیرد، همه با هم بررسی می‌شوند. محتوای پنهان (آکاردئون‌ها و تب‌ها) هم شامل می‌شود.
- `track_links`: لینک‌های جدید یا حذف‌شده هم گزارش می‌شوند، حتی اگر متن لینک ثابت مانده و فقط آدرسش عوض شده باشد (مثلاً فرم PDF جدید).
- `crawl`: صفحهٔ اصلی هر `interval_seconds` بررسی می‌شود. کل بخش هر `crawl.interval_seconds` خزیده می‌شود. هر لینک جدیدی که در صفحهٔ اصلی ظاهر شود، فوراً بررسی و به‌عنوان «صفحهٔ جدید» با متنش گزارش می‌شود.

### `items` — فهرست خبرها، اطلاعیه‌ها، کانال عمومی تلگرام
```json
{
  "id": "telegram_channel",
  "type": "items",
  "url": "https://t.me/s/bbcpersian",
  "item_selector": ".tgme_widget_message_wrap",
  "item_link_selector": "a.tgme_widget_message_date",
  "interval_seconds": 60
}
```
هر عنصرِ مطابق `item_selector` یک «مورد» است که با لینکش شناخته می‌شود. فقط موارد جدید (با عنوان، متن و لینک) گزارش می‌شوند. برای کانال تلگرام کافی است نام کانال را در `https://t.me/s/<نام>` بگذارید. `inspect` فهرست‌های مناسب هر سایت را پیدا می‌کند.

### `feed` — RSS یا Atom (سبک‌ترین و سریع‌ترین روش برای سایت‌های خبری)
```json
{ "id": "bbc_rss", "type": "feed", "url": "https://feeds.bbci.co.uk/persian/rss.xml", "interval_seconds": 60 }
```

## مرجع تنظیمات

**بخش اصلی:**

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `telegram.token` | — | توکن ربات (یا متغیر محیطی `TELEGRAM_BOT_TOKEN`) |
| `telegram.chat_ids` | — | فهرست شناسهٔ چت‌ها (کاربر، گروه، کانال) |
| `telegram.proxy` | `null` | اگر تلگرام فیلتر است: `"http://127.0.0.1:8080"` یا `"socks5://127.0.0.1:1080"` (برای socks: `pip install aiohttp-socks`) |
| `telegram.commands` | `true` | فعال بودن دستورات `/status`، `/check` و `/list` |
| `timezone` | `Asia/Tehran` | منطقهٔ زمانی نمایش ساعت |
| `daily_report_hour` | `9` | ساعت ارسال گزارش روزانه (`null` = خاموش) |
| `notify_startup` | `true` | پیام «شروع به کار» |
| `history_days` | `30` | مدت نگهداری تاریخچه |
| `browser.channel` | `chrome` | `chrome` (کروم نصب‌شده) یا `chromium`؛ اگر در دسترس نباشد، خودکار جایگزین می‌شود |
| `browser.headless` | `true` | `false` = نمایش مرورگر (در لینوکس به Xvfb نیاز دارد) |
| `browser.max_pages` | `2` | تعداد صفحات هم‌زمان مرورگر |
| `browser.block_resources` | `true` | عدم دانلود عکس و فونت برای سرعت بیشتر |
| `global_proxy` | `null` | پروکسی برای همهٔ سایت‌ها |
| `defaults` | — | هر کلید بخش بعدی؛ برای همهٔ سایت‌ها اعمال می‌شود |

**هر سایت (`watches`):**

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `id` | — | شناسهٔ لاتین یکتا (مثل `de_visa`) |
| `name` | `id` | نام نمایشی در پیام‌ها |
| `url` | — | آدرس کامل |
| `type` | `page` | `page`، `items` یا `feed` |
| `engine` | `auto` | `http` (سریع)، `browser` (برای JS یا ضدربات)، `auto` (اول HTTP، در صورت نیاز مرورگر) |
| `selector` | کل صفحه | CSS selector بخش موردنظر |
| `exclude_selectors` | `[]` | بخش‌هایی که باید نادیده گرفته شوند (ساعت، شمارنده، تبلیغ) |
| `ignore_patterns` | `[]` | عبارت‌های منظم (regex) که از متن حذف می‌شوند، مثلاً `"Updated: .*"` |
| `track_links` | `false` | گزارش لینک‌های جدید و حذف‌شده |
| `keywords` | `[]` | کلمات مهم؛ تغییرات حاوی آن‌ها با 🚨 علامت می‌خورند |
| `only_keywords` | `false` | فقط تغییرات دارای کلمهٔ کلیدی ارسال شوند (بقیه در تاریخچه می‌مانند) |
| `interval_seconds` | `120` | فاصلهٔ بررسی (حداقل ۵) |
| `jitter_seconds` | `10` | تأخیر تصادفی اضافه برای طبیعی‌تر بودن |
| `timeout_seconds` | `30` | حداکثر زمان انتظار برای هر صفحه |
| `min_content_length` | `30` | کمتر از این تعداد کاراکتر یعنی خطا (selector شکسته یا صفحهٔ مسدود)، نه تغییر |
| `cooldown_minutes` | `0` | ۰ = هر تغییر فوراً. بیشتر از ۰ = حداکثر یک پیام در این بازه؛ بقیه تجمیع می‌شوند و **حذف نمی‌شوند** |
| `error_threshold` | `3` | هشدار خطا پس از این تعداد خطای پیاپی |
| `silent` | `false` | پیام بی‌صدا (مگر کلمهٔ کلیدی پیدا شود) |
| `item_selector` / `item_link_selector` | — | برای `type: items` |
| `crawl` | — | `max_pages` (40)، `max_depth` (2)، `interval_seconds` (900)، `include` و `exclude` (regex روی آدرس)، `same_prefix` (true)، `track_files` (true، شامل PDF و Word و…)، `selector`، `concurrency` (2) |
| `cache_bust` | `false` | افزودن پارامتر تصادفی به آدرس برای دور زدن کش CDN |
| `persist_session` | `false` | نگه‌داشتن کوکی‌ها بین بررسی‌ها (برای سایت‌های دارای چالش) |
| `proxy` | `null` | پروکسی مخصوص همین سایت |
| `verify_ssl` | `true` | برای سایت‌هایی که گواهی SSL ناقص دارند `false` کنید |
| `headers` | `{}` | هدرهای اضافه |
| `wait_ms` | `0` | انتظار اضافه بعد از بارگذاری (فقط مرورگر) |
| `enabled` | `true` | خاموش یا روشن |

کلیدهایی که با `_` شروع شوند، توضیح حساب می‌شوند و نادیده گرفته می‌شوند. کلید ناشناخته (مثلاً غلط تایپی) هشدار می‌دهد. فرمت قدیمی فایل تنظیمات (`telegram_token` و `sites`) هم هنوز کار می‌کند.

## دستورات

| دستور | کار |
|---|---|
| `run` | اجرای دائمی (پیش‌فرض) |
| `once [id ...] [--dry-run]` | یک بار بررسی همه یا چند مورد |
| `inspect URL [--browser] [--selector S] [--items S]` | تحلیل صفحه و پیشنهاد تنظیمات |
| `preview ID` | نمایش دقیق متن یا مواردی که زیر نظر است |
| `validate` | بررسی فایل تنظیمات |
| `chat-id` / `test-telegram` | پیدا کردن شناسهٔ چت / تست ارسال |
| `history [--watch ID] [--show N]` | تاریخچهٔ تغییرات و نمایش کامل یک گزارش |
| `reset ID` | پاک کردن حافظهٔ یک سایت (baseline جدید بدون پیام) |

دستورات ربات در تلگرام: `/status` (وضعیت همه)، `/check` (بررسی فوری همه)، `/list` (فهرست سایت‌ها)، `/help`.

## استقرار روی سرور لینوکس (VPS، کار ۲۴ ساعته)

کل پوشهٔ پروژه را روی سرور کپی کنید (بدون `.venv` و `data`) و اجرا کنید:
```bash
sudo bash deploy/install_service.sh
```
این اسکریپت:
- یک کاربر سیستمی ایزوله (`monitorsvc`) می‌سازد.
- برنامه را در `/opt/monitor` نصب می‌کند.
- محیط پایتون، کتابخانه‌های سیستمی مرورگر و خود مرورگر را برای همان کاربر نصب می‌کند (Chrome روی amd64، در غیر این صورت Chromium).
- تنظیمات را اعتبارسنجی می‌کند و سرویس systemd را با محدودیت منابع و سخت‌سازی امنیتی فعال می‌کند (`Restart=always`).

اجرای دوباره همین دستور، برنامه را به‌روز می‌کند و تنظیمات و داده‌های سرور دست نمی‌خورند.

```bash
journalctl -u monitor-service -f            # لاگ زنده
sudo nano /opt/monitor/monitor-config.json  # ویرایش تنظیمات
sudo systemctl restart monitor-service      # اعمال تنظیمات
sudo -u monitorsvc /opt/monitor/venv/bin/python /opt/monitor/monitor_system.py history
```
حذف کامل: `sudo systemctl disable --now monitor-service && sudo rm -rf /opt/monitor /etc/systemd/system/monitor-service.service`

> اگر سرور در ایران است و تلگرام فیلتر است، `telegram.proxy` را تنظیم کنید. بهتر است سرور خارج از ایران باشد.

## نکات سرعت و دقت

- **فاصلهٔ بررسی:** برای صفحات حساس (نوبت‌دهی) ۳۰ تا ۶۰ ثانیه و برای بقیه ۲ تا ۵ دقیقه مناسب است. فاصلهٔ خیلی کم ممکن است باعث مسدود شدن IP شود.
- **HTTP در برابر مرورگر:** اگر `inspect` نشان دهد HTTP کافی است، `engine: "http"` سریع‌ترین گزینه است. حالت `auto` در صورت نیاز خودش به مرورگر می‌رود و همان را نگه می‌دارد (`reset` این انتخاب را پاک می‌کند).
- **هشدار کاذب:** اگر بخشی از صفحه مدام عوض می‌شود (ساعت، شمارندهٔ بازدید، «آخرین به‌روزرسانی»)، آن را با `exclude_selectors` یا `ignore_patterns` حذف کنید.
- **تغییر selector:** بعد از تغییر selector یا تنظیمات مرتبط، اولین بررسی بی‌صدا یک baseline جدید ذخیره می‌کند (پیام «همه‌چیز عوض شد» نمی‌آید).
- **کش CDN:** اگر سایت پشت CDN است و تغییرات با تأخیر دیده می‌شوند، `cache_bust: true` را امتحان کنید.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `selector ... matched nothing` | ساختار صفحه عوض شده یا صفحه مسدود است. `inspect` را دوباره اجرا کنید. |
| `content too short` | selector اشتباه است، یا سایت با جاوااسکریپت ساخته می‌شود (`engine: "browser"`)، یا ربات مسدود شده است. |
| `HTTP 403` / `looks like Cloudflare` | `engine: "browser"` (و در صورت نیاز `persist_session: true` یا proxy) |
| `no browser could be launched` | `patchright install chromium` |
| `TLS/SSL error` | `engine: "browser"` یا `verify_ssl: false` |
| `Telegram API error 401` | توکن اشتباه است. |
| `chat not found` | Start را در ربات نزده‌اید یا `chat_id` اشتباه است (`chat-id` را اجرا کنید). |
| `cannot reach Telegram` | تلگرام فیلتر است: `telegram.proxy`. پیام‌ها در صف می‌مانند و بعداً ارسال می‌شوند. |
| هیچ پیامی نمی‌آید | `history` را ببینید؛ اگر تغییری ثبت شده ولی ارسال نشده، خطای ارسال در لاگ آمده است. |

## تست‌ها

```bat
.venv\Scripts\python -m unittest discover -s tests -v
```
۳۷ تست خودکار شامل این موارد است:
- استخراج متن، جدول و محتوای پنهان؛ مقایسهٔ کلمه‌به‌کلمه؛ escape شدن HTML.
- تقسیم پیام‌های طولانی؛ تلاش مجدد هنگام قطعی تلگرام (بدون از دست رفتن پیام حتی با ری‌استارت)؛ محدودیت نرخ (429).
- cooldown؛ خزش (صفحهٔ جدید، تغییرکرده، حذف‌شده و فایل PDF)؛ RSS و خبرها.
- سوییچ خودکار به مرورگر برای صفحات جاوااسکریپتی.
